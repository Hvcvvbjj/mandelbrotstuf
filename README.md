# Mandelbrot Visualization

This project is a simple Mandelbrot set viewer. After cloning the repository, you need to install the dependencies before running or testing the project.

## Installation

Run the following command to install all required packages:

```bash
npm install
```

This installs both runtime dependencies and developer tools such as `prettier`, which is listed under `devDependencies`.

## Running the server

Start the application with:

```bash
npm start
```

## Running tests

To execute the test suite, run:

```bash
npm test
```

Make sure to run `npm install` after cloning so that `prettier` and other dependencies are installed correctly.
